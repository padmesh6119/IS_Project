# 🔐 Secure Data Exchange Using Cryptographic Techniques

## Overview
This project implements a secure data exchange system using modern cryptographic standards.

## Features
- Hybrid encryption (RSA + AES-GCM)
- Digital signatures (RSA-PSS)
- PKI (CA & certificates)
- CLI tools
- Automated tests

## Installation
```bash
pip install -r requirements.txt
Usage
Generate Keys
python src/cli/keygen.py
Encrypt Data
python src/cli/encrypt.py
Decrypt Data
python src/cli/decrypt.py
Run Tests
python tests/test_crypto.py
